System Users and Their Roles

Each user should only see information and tools allowed for their role. The backend must enforce these permissions.

Super Admin

Manages system settings and user roles.

School Admin / Principal

Oversees school activities and reports.

Registrar

Manages admissions and student records.

Teacher

Works with attendance, grades, and classes.

Student

Views permitted academic information.

Parent / Guardian

Views information about their linked child.

Accountant

Manages fee and payment records.

HR Officer

Manages staff records and approved HR tasks.
